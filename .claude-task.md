## FEATURE 1 — §3.5: Next Bottle Selector (pill + picker for Predictor 3)

The T* predictor currently uses `lastFeed.volume` as the assumed next bottle size.
Instead, introduce a persistent `nextBottleWaterMl` setting that the parent controls.

### 1. `src/types/index.ts`
Add to the `Settings` interface:
```ts
nextBottleWaterMl: number;   // bottle size (water ml) assumed for next T* calculation
```

### 2. `src/lib/store.ts`
Add `nextBottleWaterMl: 90` to `DEFAULT_SETTINGS`.

### 3. `src/lib/calculations.ts`

Make `smoothedAtTime` exported (add `export` keyword).

In `findTargetAwareNext`, replace:
```ts
const milkPerBottle = waterToMilk(lastFeed.volume);
```
with a new parameter `nextBottleMilkMl`. Updated signature:
```ts
function findTargetAwareNext(
  feeds: Feed[],
  hourlyRate: number,
  dailyTargetMl: number,
  lastFeed: Feed,
  standardNext: number,
  maxCorrectionMs: number,
  nextBottleMilkMl: number
): { timestamp: number; capped: boolean }
```
Use `nextBottleMilkMl` as `targetBefore = dailyTargetMl - nextBottleMilkMl`.

Update `nextFeedTime`:
- Add `nextBottleWaterMl: number` to the `Pick<Settings, ...>` type
- Compute `const nextBottleMilkMl = waterToMilk(nextBottleWaterMl)` inside `nextFeedTime`
- Pass it to `findTargetAwareNext`

Add new exported function `bestBottleSizeNow`:
```ts
/**
 * Inverse predictor: given feeding right now, what bottle size is optimal?
 * Returns the recommended water ml (snapped to nearest standard FORMULA_TABLE entry).
 */
export function bestBottleSizeNow(
  feeds: Feed[],
  hourlyRate: number,
  dailyTargetMl: number,
  now: number
): { waterMl: number; milkMl: number; status: "optimal" | "overfed" | "capped"; deficitMl: number }
```

Implementation:
- `const currentSmoothed = smoothedAtTime(feeds, hourlyRate, now)`
- `const deficitMl = dailyTargetMl - currentSmoothed`
- If `deficitMl <= 0`: return `{ waterMl: 60, milkMl: waterToMilk(60), status: "overfed", deficitMl }`
- Find the FORMULA_TABLE entry whose `formula` value is closest to `deficitMl`
- If optimal exceeds max table entry (formula=170, water=150): return with `status: "capped"`, waterMl: 150, milkMl: 170
- Otherwise: return the closest entry with `status: "optimal"`
